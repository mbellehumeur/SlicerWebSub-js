# @slicer-hub/conference-ui

Vanilla DOM conference dialogs, presence controls, strings, icons, and helpers
for Slicer WebSub applications.

```js
import {
  createHubConferenceDialog,
  renderCastConferencePresence,
} from '@slicer-hub/conference-ui';
```

Conference REST and state helpers remain in `@slicer-hub/client`, which this
package uses as a dependency.
